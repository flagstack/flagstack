# Database migrations

FlagStack uses ordered SQL migrations managed by [Goose](https://github.com/pressly/goose).

Migrations are intentionally run as an explicit deployment step rather than automatically when the API process starts.

From the repository root, after `FLAGSTACK_DATABASE_URL` is configured (normally through `.env`):

```bash
make db-status
make db-up
make db-down
```

Create a new SQL migration with:

```bash
make db-create name=describe_change
```

The migration version is generated by Goose. Every migration must include both `-- +goose Up` and `-- +goose Down` sections and must be safe to exercise in CI against the supported PostgreSQL version.
